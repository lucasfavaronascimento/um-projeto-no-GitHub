#Documentando o Fluxo de Versionamento

##🚀Sessão 1: O Passo a Passo da Criação e Envio
**O Início** Primeiro será necessário criar um repositório, ligue apenas o README e deixa as outras opções desativadas.
**A Conexão** Para adicionar uma pasta, basta abrir o repositório, clicar em add file e selecionar o arquivo.
**O Primeiro Envio** Basta apenas clicar em commite changes, para assim salvar o repositório junto do arquivo.

##📖 Sessão 2: A Anatomia do README Perfeito
**Propósito** Serve tanto para ajudar as pessoas a aprenderem com o código, mas serve principalmente como portifólio para recrutadores poderem avaliar o recruta.
**Dados Fundamentais** Título: para indicar aos leitores sobre o que o projeto fala. Tecnologias utilizadas: Uma lista com as linguagens que compõem o projeto. Instalação: O passa a passo de como fazer o programa rodar para que o leitor consiga testar o código. funcionalidade: Exemplos do projeto sendo utilizado e funcionando. Status: Informação se o projeto foi concluído ou ainda está sendo desenvolvido.
**O Poder do Markdown** O markdown é utilizado por conta de sua praticidade, permite fazer listas bem organizadas sem a necessidade de um código complexo.
